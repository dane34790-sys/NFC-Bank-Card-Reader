# 💳 NFC Bank Card Reader

A secure NFC-based bank card reader system with PIN protection, online/offline status, and real-time balance display.

## 🚀 Features

- 🔒 **PIN Protection** - 4-digit PIN required to view card details
- 📱 **NFC Card Reading** - Tap physical NFC card to read data
- 🟢 **Online/Offline Status** - Real-time card status indicator
- 💰 **Balance Display** - Shows account balance and details
- 🔔 **Push Notifications** - System notifications on card read
- 🎨 **Glass UI** - Modern glassmorphism design
- 📱 **PWA Support** - Install as native app on mobile
- 🏦 **Mastercard Logo** - Realistic card design with chip
